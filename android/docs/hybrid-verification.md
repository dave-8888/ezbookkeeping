# 安卓 App 0.3.0 整合验证

日期：2026-09-13。版本：0.3.0 / versionCode 3。测试仅使用 Android 15 专用模拟器和独立临时 SQLite 账本，未连接日常账本或在实体手机上安装。

## 实现范围

- 顶部「对话记账 / 账本」切换，保留原生聊天、交易补全和手机端网页原有导航。
- 账本使用服务根目录下的 `/mobile`；会话消息限定配置的来源、端口、子路径和顶层文档，拒绝 iframe、跨站和非 HTTP(S) 主页面。
- 网页在初始化 stores 之前取得原生会话，令牌只在内存中使用；轮换令牌和退出同步，原生 Keystore 存储继续负责持久化。内嵌网页不撤销正在被原生使用的旧令牌，避免并发请求掉线；普通浏览器保留原有轮换行为。
- 切换保留当前网页 DOM 和表单，原生保存后标记数据过期，并刷新当前首页、明细、账户或统计页面。返回聊天时重新加载账户和分类。
- 系统返回键处理网页弹层和路由，根页面返回聊天；加载失败、旧网页、旧 WebView 有可恢复的提示。
- 系统文件选择、Blob 导出保存，外观跟随系统。网页中的浏览器应用锁不作为原生 App 的保护措施，内嵌模式不提供该入口。

## 验证

- 安卓 APK 构建成功，21 项单元测试通过，包括原有交易/API 测试和新增来源、子路径及协议边界测试；Android Lint 无错误。
- 网页 `vue-tsc --noEmit`、本次涉及文件的 ESLint 和生产构建通过。生产构建仍有原有的大包体积与 Browserslist 数据更新提示。
- 3 组相关网页测试共 19 项通过，其中 4 项新增测试覆盖原生会话初始化、轮换/退出、账号及子路径隔离、普通浏览器不受影响与握手超时。
- `HybridFlowTest` 在模拟器验证免二次登录、网页→原生→网页的令牌更新、未完成表单保留、iframe 不能退出或替换会话、网页退出返回原生登录。
- 原生回归与桥接测试共 7 项通过，涵盖日夜主题、双重验证、自动记账、补全交易、Activity 重建、登录记录管理及 Room 隔离/中断恢复；另有 1 项实际网页端到端测试通过。
- `RealLedgerTest` 使用实际生产构建的手机端网页与隔离后端，验证首页、账户、交易明细、AI 设置；原生识别并保存支出后，首页金额改变且明细可见；系统返回和日夜模式通过。
- 文件测试实际导出文本到系统下载目录，读取并核对字节，再通过系统选择器选回网页核对内容，验证取消选择后仍可继续使用。没有用浏览器模拟对象代替 Android 文件选择器。
- APK 调试签名 v2 验证通过，SHA-256：`e28426bcdbccc7f6e6c4dcb085932788acd9958d249a4d81413c4824418a829d`。

## 交付与使用边界

APK：`android/app/build/outputs/apk/debug/app-debug.apk`。网页资源：项目根目录 `dist/`，由 `npm run build` 生成。两者应同步更新；后端 API 和数据库结构不需修改。通过现有 `run.sh` 启动且静态目录为 `dist/` 的本机服务可以直接读取本次构建资源。

这仍是调试签名测试包，未做商店发布。实际手机、实际代理部署和外部 AI 厂商未在本次验证中覆盖。文件导出限制为单文件 20 MB，更大文件请使用浏览器。浏览器 PIN / WebAuthn 锁不能覆盖原生聊天，因此本次未将其宣称或实现为原生应用锁。网页表单在入口切换时保留；进程结束或网页重新加载后按原网页自身的草稿机制恢复。
