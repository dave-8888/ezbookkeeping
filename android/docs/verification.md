## 隔离后端验证

使用现有本地 Go 后端程序，启动在临时端口 18991，数据库、日志、配置和测试账号全部位于独立临时目录。没有连接或修改日常账本。

收入和支出分别验证添加、按 ID 回读，金额、账户和分类一致；相同 `clientSessionId` 重复提交返回相同交易 ID。

模拟器通过宿主机访问地址连接该真实后端，使用本地模拟模型完成文字识别 → 添加交易 → 聊天成功回执。强制停止并重新启动 App 后，聊天恢复，数据库交易数量不增加。截图 `chat-mvp.png` 来自这次实际运行。
